# Unidade Referência 2026

Sistema completo de competições por unidades com pontuação, ranking, upload de evidências e calendário automático de 2026.

## Requisitos
- Docker
- Docker Compose

## Rodar
docker-compose up --build

Acesse:
Frontend: http://localhost:3000
Backend: http://localhost:8000
Admin: http://localhost:8000/admin
